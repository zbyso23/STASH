# STASH Go reference implementation — status

Spec: `SPEC.md` (STASH 2.0 R10 with Erratum E1, wire `0x0006`). Go 1.24+.

## Milestone 1 — wire constants and fixed-size structures (done)

| Package | Content | SPEC |
|---|---|---|
| `internal/checked` | overflow-checked add/sub/mul/range helpers | §16.1 |
| `internal/wire` | constants, error classes, CRC32C | §2–§7, §16 |
| | Archive Header codec + validation (legacy versions 0x0002–0x0005 refused as `ErrLegacyVersion`) | §2.2, §2.3, §7, §14 |
| | `root.current` codec | §2.1.1 |
| | Allocator State codec, kinds 0–4, reservation block and SKIP policy | §2.1.3 |

| | Master Trailer codec + `ValidateTrailer` (block types, placement, STORE length, parity invariants) | §6.2, §6.6, §7 |
| | frame tail reverse parse with outer Pre-Trailer CRC | §6.4.3 |
| | frame grid, FIXED slots, exact payload budget, parity shard length | §3, §6.3, §7.1 |
| | physical index header and record codecs | §10.5 |
| | canonical LEB128 `path_len` | §6.4.1 |

Tests (`go test ./...`):

- golden vectors from `testdata/gen/gen_golden.py`, an independent Python generator (own CRC32C, `struct.pack`); checked encoder→bytes, bytes→decoder, round trip (§17.1);
- every single-bit flip of the Frame Prefix, of the Master Trailer + `pre_trailer_len` + minimal Pre-Trailer, of `root.current` and of Allocator State is rejected (§17.2);
- arithmetic boundaries 0 / max / max+1 / MaxUint32 / MaxUint64 / overflow / truncation (§17.4);
- fuzz targets for every decoder (`go test ./internal/wire -fuzz FuzzDecodeArchiveHeader`, …) (§17.3).

Regenerate golden vectors: `python3 testdata/gen/gen_golden.py`.

## Milestone 2 — Pre-Trailer, canonical paths, object_id, complete frames (done)

| Package | Content | SPEC |
|---|---|---|
| `internal/canonpath` | canonical path validation and NFC normalization; NFC from `golang.org/x/text` tables 15.0.0 (checked at init); own table of code points assigned in Unicode 15.0 (`assigned15.go`, generated by `gen_assigned.go` from Go's 15.0.0 tables) | §6.4.5 |
| `internal/ident` | payload hash (SHA-256, BLAKE3) and `object_id` (unkeyed, and keyed HMAC-SHA-256 for encrypted archives) | §4, §6.5 |
| `internal/wire` | plaintext Pre-Trailer entry list codec | §6.4.2 |
| `internal/frame` | `Build` and `Parse` of complete frames: DATA, PACKED, PARITY, VARIABLE and FIXED, minimal size selection, 112-byte parity padding, all cross-checks (placement, object_id, PACKED order/density, STORE length, zero padding, hash) | §6, §7.1, §7.2, §8 |

Tests: golden frames and object ids from `testdata/gen/gen_golden_m2.py` (independent; Go encoder output must equal them byte for byte, automatic size selection too); the Unicode 15.0 table is compared range by range with one derived independently from Python's 15.1 data minus the 627 code points added in 15.1; BLAKE3 known answer; semantic corruption tests; fuzz `FuzzParse`, `FuzzDecodeEntries`, `FuzzValidate`.

Not yet in this milestone: encrypted frames (built by the crypto milestone; parsed keylessly now), zstd payload decoding, BLAKE3 golden frames from an independent BLAKE3 source.

Dependencies: `golang.org/x/text`, `github.com/zeebo/blake3` (run `go mod download` once with network access).
